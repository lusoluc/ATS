# SecurATS – Das souveräne Bewerbermanagementsystem

SecurATS ist eine Open-Source-Lösung für Ihre Infrastruktur. Sicher. Compliant. Souverän.

## Warum SecurATS?
Im Fokus steht die bedingungslose On-Premise-Sicherheit. SecurATS löst die komplexen Anforderungen hochregulierter Branchen durch 100% lokalen Betrieb. Es existieren keine externen Datenverbindungen, keine Abhängigkeiten von Cloud-Anbietern und somit kein IKT-Drittparteienrisiko. Sie behalten die vollkommene Datenhoheit über jeden Schritt Ihres Bewerbungsprozesses.

## Kernfunktionen
*   **Datensouveränität:** Vollständige Isolierung Ihrer Bewerberdaten. Keine externen APIs.
*   **Transparenz:** Audit-sicherer, quelloffener Code ohne versteckte Tracker oder Telemetrie.
*   **Lokale Sprachmodell-Unterstützung:** Intelligente Profilauswertung rein On-Premise, ohne Datentransfer nach außen.
*   **Compliance-Fokus:** DSGVO-konform durch Design. Erfüllt DORA, Art. 9 DSGVO sowie DSG-EKD / KDG.

## Installation
SecurATS ist auf maximale Prozessstabilität ausgelegt und bietet sofortige Docker-Container-Bereitschaft. 

\`\`\`bash
# Repository klonen
git clone https://github.com/lusoluc/ATS.git securats

# Ins Verzeichnis wechseln
cd securats

# Docker-Umgebung starten
docker-compose up -d
\`\`\`
*(Innerhalb von 30 Sekunden läuft das System isoliert in Ihrer Infrastruktur)*
