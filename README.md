# Landesverein Karriereplattform & Enterprise ATS

Eine voll integrierte, quelloffene Enterprise Recruiting-Plattform. 
Entwickelt mit höchsten Ansprüchen an Datensicherheit, DSGVO-Compliance, KRITIS-Standards und UX/UI-Design.

## Architektur
Details zur System-Architektur, lokalen KI (Gemma) und SAP-Integration entnehmen Sie bitte der Datei `System_Architektur_und_Feature_Katalog.md`.

## Features
- **Zero-Data-Transfer KI:** Lokale Analysen von Lebensläufen mit gemma4:e4b (via Ollama).
- **Compliance:** DSGVO Auto-Deletion Cronjobs, AGG-Checker, Air-gapped fähig.
- **Enterprise-ready:** Modulare SAP SuccessFactors "Candidate-to-Employee" API Bridge mit visuellem Field Mapper.
- **CMS:** Visueller Page Builder (Puck) mit Drag-and-Drop.
- **BA XML Export:** Vollautomatische Vakanzen-Einspeisung.
