SAP SuccessFactors Sync Console

Bilden Sie Ihre SecurATS-Felder auf die Felder Ihres HRIS ab. Die eigentliche Übertragung übernimmt der Server-Befehl hris_export – nur bei konfiguriertem Endpunkt.

So funktioniert die Übertragung

Diese Seite überträgt keine Daten. Sie legt fest, welches SecurATS-Feld auf welches HRIS-Feld abgebildet wird (rechts).

  1. Feldzuordnung rechts prüfen und speichern.
  2. Auf dem Server den Befehl python manage.py hris_export ausführen (oder per Cron planen).
  3. Die Übertragung erfolgt nur, wenn HRIS_ENDPOINT gesetzt ist – sonst bricht der Befehl ehrlich ab.

Jede echte Übertragung wird revisionssicher protokolliert – mit dem tatsächlichen Ergebnis, nicht mit einer erfundenen Bestätigung.
